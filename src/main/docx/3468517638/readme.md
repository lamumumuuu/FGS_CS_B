## *成果介绍*
- 用户注册功能：
    - 接收用户名、邮箱和密码
    - 验证用户名和邮箱是否唯一
    - 对密码进行加密存储
- 用户登录功能：
    - 支持用户名或邮箱登录
    - 登录成功后生成JWT令牌
    - 返回用户信息和令牌
- 忘记密码功能：
    - 发送验证码到用户邮箱
    - 验证码通过Redis存储，5分钟过期（redis在application.yml处修改一直不正确，请各位帮忙修改一下）
    - 验证码正确后可以重置密码
