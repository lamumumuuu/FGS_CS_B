## 7. 环境搭建详细步骤

### 7.1 Windows 环境搭建

#### 7.1.1 安装 JDK 17

**步骤 1: 下载 JDK**

- 访问 Eclipse Temurin 官网: https://adoptium.net/
- 选择 JDK 17 (LTS)
- 下载 Windows x64 Installer (.msi)

**步骤 2: 安装 JDK**

1. 运行下载的安装程序
2. 按照提示完成安装（建议使用默认路径）
3. 安装过程中勾选 "Set JAVA_HOME" 和 "Add to PATH"

**步骤 3: 验证安装**

打开命令提示符（CMD 或 PowerShell），执行：

```cmd
java -version
javac -version
echo %JAVA_HOME%
```

预期输出：
```
java version "17.0.x"
javac 17.0.x
C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot\
```

#### 7.1.2 安装 Maven（可选）

> 项目已包含 Maven Wrapper（mvnw），可跳过此步骤。

**步骤 1: 下载 Maven**
- 访问 https://maven.apache.org/download.cgi
- 下载 Binary zip archive
- 解压到指定目录（如 C:\Program Files\Apache\maven）

**步骤 2: 配置环境变量**
1. 新建系统变量 MAVEN_HOME，值为 Maven 安装路径
2. 在 Path 变量中添加 %MAVEN_HOME%\bin

**步骤 3: 验证安装**
```cmd
mvn -version
```

#### 7.1.3 安装 PostgreSQL

**步骤 1: 下载安装包**
- 访问 https://www.postgresql.org/download/windows/
- 下载 PostgreSQL 16.x Windows 安装包

**步骤 2: 安装 PostgreSQL**
1. 运行安装程序
2. 选择安装路径（默认 C:\Program Files\PostgreSQL\16）
3. 选择组件（默认全选：PostgreSQL Server、pgAdmin 4、Stack Builder、Command Line Tools）
4. 设置数据目录（默认即可）
5. **设置 postgres 用户密码（请务必记住此密码）**
6. 设置端口（默认 5432）
7. 选择语言区域（Default locale）
8. 完成安装

**步骤 3: 验证安装**

打开命令提示符，执行：
```cmd
cd "C:\Program Files\PostgreSQL\16\bin"
psql --version
```

**步骤 4: 启动/停止服务**

```cmd
# 启动服务
net start postgresql-x64-16

# 停止服务
net stop postgresql-x64-16
```

或在服务管理器中操作：
1. Win + R 输入 services.msc
2. 找到 "postgresql-x64-16"
3. 右键启动/停止

#### 7.1.4 安装 Redis（Windows）

**方法一：使用 Memurai（推荐）**

Memurai 是 Redis 在 Windows 上的兼容实现：
- 访问 https://www.memurai.com/
- 下载并安装社区版

**方法二：使用 WSL**

1. 安装 WSL（适用于 Linux 的 Windows 子系统）
2. 在 WSL 中安装 Redis

**方法三：使用 Docker（如果已安装 Docker）**

```cmd
docker run -d -p 6379:6379 --name redis redis:latest
```

> **注意**: 开发阶段如果暂时不启用 Redis 相关功能，可暂不安装，Redis 连接失败不影响核心用户认证功能。

#### 7.1.5 安装 Node.js（前端开发）

**步骤 1: 下载 Node.js**
- 访问 https://nodejs.org/
- 下载 LTS 版本（18.x 或 20.x）
- 运行安装程序，按默认选项安装

**步骤 2: 验证安装**

```cmd
node -v
npm -v
```

#### 7.1.6 安装 Git

**步骤 1: 下载 Git**
- 访问 https://git-scm.com/download/win
- 下载并运行安装程序

**步骤 2: 安装选项**
- 选择安装路径
- 勾选 "Git Bash Here"、"Git GUI Here"
- 默认编辑器选择 VS Code（如已安装）
- PATH 环境选择 "Git from the command line and also from 3rd-party software"
- 其他保持默认即可

**步骤 3: 验证安装**

```cmd
git --version
```

## 8. 项目配置与启动

### 8.1 获取项目代码

```cmd
# 如果使用 Git
git clone <项目仓库地址>
cd fgs2026-01-24-service-master

# 或直接解压已有的项目压缩包
```

### 8.2 配置环境变量

**步骤 1: 创建 .env 文件**

复制项目根目录下的 [.env.example](file:///c:/Users/admin/Desktop/fgs2026-01-24-service-master/.env.example) 为 `.env`：

```cmd
copy .env.example .env
```

**步骤 2: 修改 .env 配置**

用文本编辑器打开 `.env` 文件，根据实际情况修改：

```env
# 数据库配置
DB_HOST=localhost
DB_PORT=5432
DB_NAME=computer_association
DB_USERNAME=postgres
DB_PASSWORD=你的数据库密码

# 邮件配置（可选，开发环境可暂不配置）
MAIL_HOST=smtp.163.com
MAIL_PORT=465
MAIL_USERNAME=your_email@163.com
MAIL_PASSWORD=your_email_auth_code
MAIL_FROM=your_email@163.com

# JWT 配置
JWT_SECRET=你的JWT密钥至少32个字符长度的字符串
JWT_EXPIRATION=86400
```

> **注意**: JWT_SECRET 建议使用至少 32 个字符的随机字符串。

### 8.3 创建数据库

**方法一：使用 pgAdmin**

1. 打开 pgAdmin 4
2. 连接 PostgreSQL 服务器
3. 右键 Databases -> Create -> Database
4. Database 输入: computer_association
5. Owner 选择: postgres
6. 点击 Save

**方法二：使用命令行**

```cmd
cd "C:\Program Files\PostgreSQL\16\bin"
psql -U postgres
```

在 psql 中执行：
```sql
CREATE DATABASE computer_association;
\q
```

### 8.4 启动后端服务

**步骤 1: 进入项目目录**

```cmd
cd c:\Users\admin\Desktop\fgs2026-01-24-service-master
```

**步骤 2: 使用 Maven Wrapper 启动**

```cmd
# Windows 系统
mvnw.cmd spring-boot:run
```

或在 IntelliJ IDEA 中：
1. 打开项目
2. 等待 Maven 依赖下载完成
3. 找到 [ComputerAssociationApplication.java](file:///c:/Users/admin/Desktop/fgs2026-01-24-service-master/src/main/java/com/example/computerassociation/ComputerAssociationApplication.java)
4. 右键点击 main 方法，选择 Run

**步骤 3: 验证启动**

打开浏览器访问：
- 健康检查: http://localhost:8080/actuator/health
- Swagger 文档: http://localhost:8080/swagger-ui/index.html

健康检查应返回：
```json
{"status":"UP"}
```

```
The JAVA_HOME environment variable is not defined correctly
```

**解决方案**:
1. 右键"此电脑" -> "属性" -> "高级系统设置" -> "环境变量"
2. 新建系统变量 JAVA_HOME，值为 JDK 安装路径
3. 在 Path 变量中添加 %JAVA_HOME%\bin
4. 重启命令提示符

### 9.2 数据库相关问题

#### 问题：连接数据库失败

**现象**:
```
FATAL: password authentication failed for user "postgres"
```

**解决方案**:
1. 确认数据库服务已启动
2. 检查 .env 文件中的 DB_PASSWORD 是否正确
3. 重置 postgres 用户密码：
   ```cmd
   psql -U postgres
   ALTER USER postgres WITH PASSWORD '新密码';
   ```

#### 问题：数据库不存在

**现象**:
```
FATAL: database "computer_association" does not exist
```

**解决方案**:
创建数据库，参考 8.3 节。

### 9.3 Maven 相关问题

#### 问题：依赖下载慢

**解决方案**: 配置 Maven 国内镜像

1. 找到 Maven 配置文件（用户目录下的 .m2/settings.xml）
2. 添加阿里云镜像：

```xml
<mirrors>
  <mirror>
    <id>aliyunmaven</id>
    <mirrorOf>*</mirrorOf>
    <name>阿里云公共仓库</name>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```

#### 问题：端口 8080 被占用

**现象**:
```
Web server failed to start. Port 8080 was already in use.
```

**解决方案**:

```cmd
# 查找占用 8080 端口的进程
netstat -ano | findstr 8080

# 终止进程（替换 PID 为实际进程号）
taskkill /F /PID <PID>
```

或修改项目端口（application.yml）：
```yaml
server:
  port: 8081
```

### 9.4 Redis 相关问题

#### 问题：Redis 连接失败

**现象**:
```
Unable to connect to Redis
```

**解决方案**:
- 启动 Redis 服务
- 或在开发环境中暂时不使用 Redis 相关功能
- 检查 application-redis.yml 中的配置是否正确

### 9.5 邮件服务问题

#### 问题：邮件发送失败

**解决方案**:
1. 确认 MAIL_USERNAME 和 MAIL_PASSWORD（授权码）正确
2. 确认 163 邮箱已开启 SMTP 服务
3. 检查网络是否能访问 smtp.163.com:465

> 开发环境如无邮件服务，可暂不配置，注册和重置密码功能可能受限。
